# The Staff Room 1.0.0 release record

**Historical record, not a current recommendation.** The `1.0.0` designation overstated the project's maturity. Current development is experimental and pre-1.0 (`0.1.0`); there is no supported stable binary. The earlier tag, artifact identities, and observations below are preserved without rewriting their evidence. They do not satisfy the [current provider boundary acceptance gates](../PROVIDER_BOUNDARY_ACCEPTANCE.md).

## Acceptance boundary

Human-gated Ask, Quick Edit, Ship, Apply, Promote, cancellation, recovery, migration, and supported live-provider routes are accepted for this Windows release. Final Apply and Promote decisions remain under human control.

Fully unattended operation is intentionally disabled in 1.0.0. Autonomous mode remains locked and fail-closed under its [separate acceptance contract](../AUTONOMOUS_ACCEPTANCE_CONTRACT.md).

The lockfile contains a Linux-only transitive `glib` advisory that is absent from the supported Windows dependency graph. It must be reassessed before adding non-Windows support.
