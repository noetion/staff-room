# About this bundled skill

Despite the historical directory name, this skill does not enable autonomous mode or unattended promotion.

Its only job is to recognize a substantial repository request and emit a structured proposal for The Staff Room's human-gated Ship route. The proposal cannot write to the attached checkout, press Apply, confirm Promote, change the autonomous acceptance constant, or bypass any Rust-owned custody check.

Autonomous mode remains locked and fail-closed in 1.0.0. See the [public autonomous acceptance contract](../../../docs/AUTONOMOUS_ACCEPTANCE_CONTRACT.md) for the controls and evidence required before that can change.
